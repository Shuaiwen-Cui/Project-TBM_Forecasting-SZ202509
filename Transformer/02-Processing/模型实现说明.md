# 模型实现说明

## 问题修复

### 原问题
所有64个实验都失败，错误信息显示模型未实现（`No module named 'models.xxx_model'`）。

### 解决方案
已实现所有4个模型：
1. **ARIMA模型** (`models/arima_model.py`)
2. **LSTM模型** (`models/lstm_model.py`)
3. **1D-CNN模型** (`models/cnn1d_model.py`)
4. **Transformer模型** (`models/transformer_model.py`)

## 模型实现细节

### 1. LSTM模型
- **架构**: 基于PyTorch的LSTM网络
- **配置**: hidden_size=64, num_layers=2, dropout=0.1
- **特点**: 使用最后一个时间步的输出，然后递归预测pred_len步

### 2. 1D-CNN模型
- **架构**: 一维卷积神经网络
- **配置**: num_filters=64, kernel_size=3, num_layers=2, dropout=0.1
- **特点**: 使用卷积提取特征，然后通过全连接层输出预测

### 3. Transformer模型
- **架构**: 基于Transformer编码器
- **配置**: d_model=64, nhead=4, num_layers=2, dim_feedforward=256, dropout=0.1
- **特点**: 使用自注意力机制，能够捕捉长距离依赖

### 4. ARIMA模型
- **架构**: 统计时间序列模型
- **配置**: order=(2,1,2)
- **特点**: 对每个特征分别建模（ARIMA是单变量模型）

```bash
cd Transformer/02-Processing

```

## 注意事项

1. **依赖安装**: 确保安装了所有依赖
   ```bash
   pip install numpy pandas scikit-learn torch statsmodels psutil
   ```

2. **ARIMA模型**: ARIMA是单变量模型，对每个特征分别建模，可能训练时间较长

3. **GPU支持**: PyTorch模型（LSTM、1D-CNN、Transformer）会自动使用GPU（如果可用）

4. **内存使用**: 每个实验独立加载数据，用完即释放，适合长时间运行

## 模型接口

所有模型都实现了 `BaseModel` 接口：
- `train()`: 训练模型
- `predict()`: 预测
- `save()`: 保存模型
- `load()`: 加载模型
