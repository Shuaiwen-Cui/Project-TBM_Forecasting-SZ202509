# 四种方法公平对比实验设计

为确保 ARIMA、LSTM、1D-CNN、Transformer 四种方法具有可比较性，实验设计遵循以下原则：**同一任务、同一数据、同一评估、同一协议**。

---

## 一、已满足的公平性条件

| 维度 | 设计 | 说明 |
|------|------|------|
| **数据源** | 同一 `data_preprocessed.csv` | 所有模型使用同一预处理数据 |
| **归一化** | 同一 MinMaxScaler，先 fit 再统一 transform | 在序列构造前对全段 fit，避免信息泄露 |
| **划分方式** | 时间顺序 7:1.5:1.5，不打乱 | `TRAIN_RATIO / VAL_RATIO / TEST_RATIO`，`SHUFFLE=False` |
| **任务定义** | 同一 (seq_len, pred_len) 网格 | 输入形状 (seq_len, n_features)，输出 (pred_len, n_features) |
| **评估指标** | MSE, MAE, RMSE, MAPE, R² | 在**同一测试集**上，将 (n_samples, pred_len, n_features) 展平后计算 |
| **评估方式** | 逐样本输入→输出 | 每个测试样本用各自的 X_test[i] 得到 Y_pred[i]，再与 Y_test[i] 比较 |

---

## 二、需要统一或加强的设计

### 2.1 输入信息对齐（ARIMA）

- **现状**：深度学习模型对每个测试样本使用 **该样本的输入窗口** `X_test[i]`（长度 seq_len）做预测；ARIMA 当前是用训练末端的全局状态做 `forecast(steps=pred_len)`，**没有使用** `X_test[i]`。
- **建议**：ARIMA 在预测时对每个测试样本、每个特征，用该样本的输入序列 `X_test[i, :, f]`（长度 seq_len）通过 `apply()` 更新状态后再 `forecast(steps=pred_len)`，使“所见输入”与三种深度学习模型一致。
- **实现**：已在 `models/arima_model.py` 中改为按样本、按特征对待测输入序列 `X_test[i,:,f]` 调用 `apply(endog=...)` 得到新状态后再 `forecast(steps=pred_len)`，与三种深度学习模型使用相同输入信息。若 `apply` 失败（如 seq_len 过小导致状态空间初始化不足），则回退为从拟合模型直接 `forecast`，并在论文中可注明该情况。

### 2.2 可复现性（随机种子）

- **数据**：划分仅按比例、不 shuffle，已确定性；若将来引入随机性（如采样、增强），应使用 `config.RANDOM_SEED`。
- **模型**：LSTM / 1D-CNN / Transformer 在 `train()` 中应固定 `torch.manual_seed`、`numpy.random.seed`（以及若使用 `DataLoader` 的 worker 种子），保证同一配置多次运行结果可复现。
- **建议**：在 `experiment_runner` 调用 `prepare_data_for_experiment` 时传入 `config.RANDOM_SEED`；各模型从 `**kwargs` 或 config 读取 `random_seed` 并在训练前设好。

### 2.3 训练协议统一

- **epochs**：当前三种深度学习模型均为固定 `epochs=20`，便于对比。
- **早停（可选）**：若希望“收敛到稳定”的对比，可统一加入早停（如基于验证集 loss，patience=5），并约定“最多训练 N 个 epoch”；论文中需写明“固定 20 epoch”或“早停 + 最大 epoch”。
- **验证集**：当前 LSTM/CNN/Transformer 未用验证集做早停或选模型；若引入早停，应统一用同一验证集与规则。

### 2.4 模型规模（可选说明）

- 当前 LSTM / 1D-CNN / Transformer 均为“中等规模”（hidden/filters/d_model≈64，2 层），便于在论文中表述为“相近参数量级下的结构对比”。
- ARIMA 为每特征一个 (p,d,q)=(2,1,2)，相当于 32 个单变量模型；在文中可说明“传统统计模型与深度学习在相近任务下的对比”。

---

## 三、评估与报告建议

1. **指标**：统一报告 MSE、MAE、RMSE、MAPE、R²；如需强调某一方面，可额外给出 RMSE 或 R² 的表格。
2. **稳定性（可选）**：对 LSTM/CNN/Transformer 用 3～5 个不同随机种子各跑一次，报告均值 ± 标准差；ARIMA 确定性，报单次即可。
3. **多步预测**：当前指标是在“所有 (样本×预测步)”上整体计算，等价于对所有预测步一视同仁；若需分析“步数越远误差是否越大”，可额外按 step=1,2,…,pred_len 分别算指标。

## 四、检查清单（实现时核对）

- [x] 数据：同一文件、同一划分、同一 scaler
- [x] 任务：同一 (seq_len, pred_len) 网格
- [x] ARIMA 预测时使用测试样本输入窗口（apply + forecast）
- [x] 神经网络训练前设置 `random_seed`（由 experiment_runner 注入 config.RANDOM_SEED）
- [ ] 论文/附录中写明：固定 20 epoch、无早停、评估方式（逐样本、展平后算指标）

完成上述项后，四种方法在“同一任务、同一数据、同一评估、输入信息对齐”意义下具备公平可比性。
