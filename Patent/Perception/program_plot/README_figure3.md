# 专利附图3生成脚本使用说明

## 功能说明

本脚本用于生成专利附图3（数据预处理流程示意图）的基础可视化图表，包括：

1. **异常值检测（箱线图法）**：展示IQR算法识别异常值的过程
2. **信号去噪（小波变换）**：展示db10小波基进行信号去噪的效果
3. **特征降维（PCA）**：展示主成分分析降维的过程和效果

## 安装依赖

```bash
pip install -r requirements_figure3.txt
```

或者手动安装：

```bash
pip install numpy matplotlib scikit-learn PyWavelets
```

## 使用方法

### 基本使用

直接运行脚本：

```bash
python generate_figure3.py
```

脚本会自动生成以下文件：

- `figure3a_boxplot.png` - 异常值检测箱线图
- `figure3b_wavelet.png` - 小波变换去噪图
- `figure3c_pca.png` - PCA特征降维图
- `figure3_combined.png` - 完整组合图（推荐使用）

### 自定义参数

可以在脚本中修改以下参数：

- **箱线图阈值**：默认使用IQR方法（Q1-1.5×IQR, Q3+1.5×IQR）
- **小波类型**：默认使用'db10'，可改为其他小波基（如'db4', 'db8'等）
- **PCA降维维度**：默认降至2维用于可视化，实际应用可调整
- **图形尺寸和分辨率**：在脚本开头修改 `figsize` 和 `dpi` 参数

## 注意事项

1. **字体设置**：脚本已配置中文字体支持，如果系统没有相应字体，可能需要调整 `plt.rcParams['font.sans-serif']` 设置

2. **黑白输出**：所有图表均为黑白线条图，符合专利附图要求

3. **分辨率**：默认输出300 DPI，适合打印和专利申请

4. **数据格式**：如果使用实际数据，确保数据格式为numpy数组或可转换为数组的格式

## 常见问题

**Q: 提示找不到中文字体？**

A: 修改脚本中的字体设置，使用系统已安装的字体，或使用英文标注。

**Q: 生成的图片分辨率不够？**

A: 修改 `plt.rcParams['savefig.dpi'] = 300` 为更高值（如600）。

**Q: 如何修改颜色方案？**

A: 脚本已设置为黑白，如需修改，将 `'k'`（黑色）改为其他颜色代码。
