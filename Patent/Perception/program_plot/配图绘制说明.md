# 专利配图绘制说明

## 总体要求

1. **格式要求**：所有配图应为黑白线条图，符合中国专利申请附图规范
2. **清晰度**：线条清晰，标注明确，字体大小适中（建议使用宋体或黑体）
3. **编号**：每张图需标注"图1"、"图2"等图号，位于图的下方居中
4. **标注**：所有关键组件、流程步骤、数据流向均需清晰标注

---

## 图1：方法总体流程图

### 绘制要求

**布局**：采用从左到右的横向流程图布局，或从上到下的纵向布局

**主要内容**：
1. **起始框**：盾构掘进监测数据采集
2. **处理框**（按顺序）：
   - 数据预处理（异常检测、去噪、降维）
   - 特征解耦（主动量/被动量分离）
   - 特征提取与分类（1D-CNN）
   - 自适应学习（可选分支）
   - 反馈输出
3. **结束框**：盾构控制系统参数调节

**绘制细节**：
- 使用矩形框表示处理步骤
- 使用箭头表示数据流向（标注"数据流"）
- 数据预处理框内可细分为三个子框（异常检测、去噪、降维），用虚线框或子流程表示
- 自适应学习框应标注为"循环反馈"或"在线更新"
- 反馈输出框应标注"闭环控制"

**标注示例**：
```
[数据采集] → [数据预处理] → [特征解耦] → [特征提取与分类] → [自适应学习] → [反馈输出]
     ↓              ↓              ↓                ↓              ↓            ↓
  多源参数      异常检测      主动量/被动量      1D-CNN        权重更新    参数调节
                去噪降维      特征分离          分类识别       在线优化    闭环控制
```

## 图2：系统结构示意图

### 绘制要求

**布局**：采用模块化框图，各单元用矩形框表示，通过数据总线连接

**主要内容**：
1. **数据采集单元**：标注"多路数据采集接口"、"时间戳同步模块"、"数据缓存模块"
2. **数据预处理单元**：标注"异常检测模块"、"去噪模块"、"降维模块"
3. **特征解耦单元**：标注"协方差计算模块"、"响应系数分析模块"、"特征分类模块"
4. **地层分类单元**：标注"模型推理引擎"、"结果输出模块"
5. **自适应学习单元**：标注"损失计算模块"、"阈值判断模块"、"增量训练模块"
6. **反馈控制单元**：标注"结果传输模块"、"控制策略模块"

**绘制细节**：
- 各单元用粗线框表示，内部模块用细线框或文字列表表示
- 单元之间用带箭头的连线表示数据流向，标注"数据总线"或"CAN总线"
- 可在系统外围标注"盾构机控制台"和"盾构机主控单元"，表示系统与外部设备的连接
- 数据采集单元左侧连接"盾构机监测系统"
- 反馈控制单元右侧连接"盾构机主控单元"

**布局建议**：
```
        [盾构机监测系统]
              ↓
    [数据采集单元]
         ↓
    [数据预处理单元]
         ↓
    [特征解耦单元]
         ↓
    [地层分类单元] ←→ [自适应学习单元]
         ↓
    [反馈控制单元]
         ↓
    [盾构机主控单元]
```

## 图3：数据预处理流程示意图

### 绘制要求

**布局**：采用三个并排的子流程图，展示三个预处理步骤

**主要内容**：

**子图3a：异常值检测（箱线图法）**
- 绘制一个箱线图示例
- 标注Q1、Q3、中位数、上下限（Q1-1.5×IQR、Q3+1.5×IQR）
- 标注异常点（超出上下限的点）
- 用箭头表示"剔除异常点"

**子图3b：信号去噪（小波变换）**
- 绘制原始信号曲线（含噪声）
- 绘制去噪后信号曲线（平滑）
- 标注"db10小波基"、"小波分解"、"重构"
- 用箭头表示处理流程

**子图3c：特征降维（PCA）**
- 绘制高维特征空间示意图（如3D散点图）
- 绘制降维后的低维特征空间（如2D散点图）
- 标注"主成分分析"、"累计贡献率≥95%"
- 用箭头表示降维过程

**绘制细节**：
- 三个子图可用虚线框分隔
- 每个子图下方标注处理步骤名称
- 可在图下方添加说明文字："原始数据 → 异常检测 → 去噪 → 降维 → 预处理后数据"

## 图4：特征解耦机制原理示意图

### 绘制要求

**布局**：采用左右分栏或上下分栏布局

**主要内容**：

**左侧/上方：解耦前**
- 绘制混合特征示意图（如特征向量或特征矩阵）
- 标注"控制信号"和"地层反馈"混合在一起
- 用不同颜色或线型区分（黑白图可用实线/虚线）

**中间：解耦过程**
- 绘制协方差矩阵计算示意图（矩阵形式）
- 标注"响应系数计算"、"阈值判定（0.7）"

**右侧/下方：解耦后**
- **主动量分支**：标注"推进速度"、"刀盘转速"等，标注"受控制指令主导"
- **被动量分支**：标注"刀盘扭矩"、"推进油缸压力"、"贯入度"等，标注"反映地层反馈"

**绘制细节**：
- 可用流程图形式：`[混合特征] → [协方差分析] → [响应系数判定] → [特征分类] → [主动量/被动量]`
- 在响应系数判定处标注阈值线（如0.7）

**标注示例**：
```
[监测参数] → [协方差矩阵计算] → [响应系数分析] → [阈值判定(0.7)]
                                                      ↓
                                    ┌─────────────────┴─────────────────┐
                                    ↓                                   ↓
                              [主动量]                            [被动量]
                          推进速度、刀盘转速                  扭矩、压力、贯入度
                          受控制指令主导                      反映地层反馈
```

## 图5：一维卷积神经网络（1D-CNN）结构示意图

**布局**：采用纵向分层结构，展示网络的前向传播过程

**主要内容**（从上到下）：

   - 标注"零填充"、"步长=1"

3. **批归一化层1**
   - 标注"BatchNorm"

4. **ReLU激活层1**
   - 标注"ReLU"

5. **第二卷积层**
   - 标注"Conv1D"、"通道数=32"、"卷积核=3"
   - 绘制卷积操作示意图

6. **批归一化层2**
   - 标注"BatchNorm"

7. **ReLU激活层2**
   - 标注"ReLU"

## 图6：自适应学习机制流程图

### 绘制要求

**布局**：采用循环流程图，展示自适应学习的闭环过程

**主要内容**：

1. **起始**：新数据采集
2. **模型推理**：使用当前模型进行预测
3. **损失计算**：计算预测结果与验证数据的差异
4. **阈值判断**：判断损失是否超过阈值（如0.1）
   - 如果未超过：继续使用当前模型
   - 如果超过：触发权重微调
5. **权重微调**：采用小学习率（0.0001）进行增量训练
6. **模型更新**：更新模型权重
7. **循环反馈**：返回模型推理步骤

**绘制细节**：
- 使用菱形框表示判断节点（阈值判断）
- 使用矩形框表示处理步骤
- 用箭头表示流程方向
- 阈值判断处用两个分支：一个是"否"（继续使用），一个是"是"（触发更新）
- 可在图中标注关键参数：损失阈值=0.1，学习率=0.0001

**标注示例**：
```
[新数据采集] → [模型推理] → [损失计算] → [阈值判断(0.1)]
                                              ↓
                                        是否超过阈值？
                                        ↙        ↘
                                    [否]        [是]
                                     ↓            ↓
                              [继续使用]    [权重微调] → [模型更新]
                                     ↓            ↓
                                    └────→ [模型推理] ←┘
```

## 绘图工具建议

1. **专业绘图软件**：
   - Visio（流程图、系统结构图）
   - AutoCAD（精确线条图）
   - PowerPoint（简单流程图）
   - Draw.io（在线流程图工具）

2. **编程工具**（用于数据可视化图）：
   - Python + Matplotlib（图7对比图）
   - MATLAB（信号处理相关图）

3. **注意事项**：
   - 所有图最终需转换为黑白线条图
   - 确保打印后清晰可辨
   - 标注文字使用中文，字体清晰
   - 线条粗细适中，关键部分可用粗线
